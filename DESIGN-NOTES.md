# Multipage editorial redesign

## Visual direction

- White and warm cream are the dominant canvases.
- Deep blue provides structure in navigation, headings, selected bands, and the footer.
- Gold is used selectively for buttons, rules, dates, numbers, and emphasis.
- The homepage uses a static three-image collage rather than a large rotating image carousel.
- The homepage ministry preview is a vertical editorial directory with offset imagery, not a two-column card wall.
- The full Ministries page uses alternating image/text stories with white, soft-gold, and soft-blue background bands.

## Pages

- `index.html` — Home
- `about.html` — Story, pastor, leadership, vision, values
- `ministries.html` — Full ministry catalogue
- `events.html` — Events, filters, registration
- `giving.html` — Giving information
- `connect.html` — Visit, contact, membership, prayer, pastoral care
- `privacy-policy.html` — Privacy notice

## Deployment

Keep the existing `images/` directory alongside these files. The shared form endpoints remain unchanged.
